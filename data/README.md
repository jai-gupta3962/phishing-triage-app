# Data

The repository includes the CEAS 2008 email dataset used for training the text classification model.

The dataset is stored as `data/CEAS_08.zip` and can be extracted to obtain `data/CEAS_08.csv`.

The CSV is required when running `train_model.py` to retrain the NLP model. The application can use the supplied trained model without the CSV when the model file is present.
